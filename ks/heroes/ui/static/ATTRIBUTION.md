# Icon attribution

## Gear

Piece icons under `gear-pieces/` downloaded from
[Kingshot Optimizer](https://kingshotoptimizer.com/) (`/images/icons/gear-pieces/`)
on 2026-08-01 for local private use in this KS tooling UI.

## Heroes

Portraits under `heroes/` vendored from
[Kingshot Database](https://kingshotdata.com/) (`/uploads/…/*avatar*.webp` etc.)
on 2026-08-02 for local private use; Gen 2 portraits (Zoe, Marlin, Hilde) added
2026-08-24 from the same source. Letter SVGs are generated when no portrait
is present.

## Troops

Placeholder SVG tier badges under `troops/` (`{type}-t{n}.svg`) ship with the
UI. Replace with vendored webp/png from public Kingshot data sites when
available; `troop_icon_url` prefers webp/png over svg.
